What is ChatGPT Tabs?

ChatGPT, with tabs.

ChatGPT Tabs is a desktop app for macOS and Windows that works like a browser built only for ChatGPT. Open a new tab for every topic, switch between them instantly, and stay signed in to the same account in all of them.

Can I really keep several chats open at the same time?

Yes. Every tab is its own ChatGPT window with its own history, so a long answer can keep writing in one tab while you work in another.

  • New tabs start fresh. They open on a new chat, never a copy of the tab you were in.
  • Switching is instant. Tabs in the background stay loaded, so you come back exactly where you left off.
  • One sign-in for all tabs. Log in once and every tab, and every future launch, uses the same account.
  • Everything from ChatGPT still works: the sidebar and chat history, model picker, settings, file and image uploads, drag and drop, voice, code blocks and downloads.
  • It isn't a browser. There is no address bar. Links to other websites open in your normal browser.

How do I install it?

Get the file for your computer from the latest release.

Your computerFile to download
Mac with Apple chip (M1 and newer)…-mac-arm64.dmg
Mac with Intel processor…-mac-x64.dmg
Windows 10 or 11…-win-x64-setup.exe
Windows, without installing…-win-x64-portable.zip

macOS

Open the .dmg and drag ChatGPT Tabs into Applications. The app is signed and notarized by Apple, so it opens like any other app.

Windows

Run the installer. It installs for your user only and needs no admin rights. Windows may say “Windows protected your PC” because the installer isn't code-signed yet: choose More info, then Run anyway.

Check the file (optional)

Each release lists a SHA-256 checksum for every file in SHA256SUMS.txt. Compare it with yours:

Terminal (macOS)
shasum -a 256 ~/Downloads/ChatGPT-Tabs-*.dmg
PowerShell (Windows)
Get-FileHash $env:USERPROFILE\Downloads\ChatGPT-Tabs-*-setup.exe

How do I sign in?

  1. Open the app and click the settings button in the top right corner.
  2. Choose Open ChatGPT Login and sign in the way you always do: email, Google, Microsoft, Apple or your company's single sign-on.
  3. The login window closes by itself and your tabs refresh. You stay signed in after restarting the app.

To sign out everywhere, use Clear ChatGPT Session in the same settings screen. It removes ChatGPT's cookies and stored data from this computer. Your conversations stay in your ChatGPT account.

Is it safe? What happens to my password and my chats?

The app shows the real ChatGPT website and stays out of the way.

  • Your password never touches the app. You type it into OpenAI's (or Google's, Microsoft's, Apple's) own sign-in page. The app keeps only the normal login cookie, encrypted on disk with your system keychain.
  • No tracking. No analytics, no telemetry, no server of its own. The only traffic is ChatGPT itself and the sign-in provider you pick.
  • Your chats are not read or changed. The app does not inject scripts into ChatGPT and sends nothing to third parties.
  • Locked-down pages. ChatGPT runs sandboxed with no access to your files or system, and links to other sites open in your own browser.
  • Hardened package. The macOS app is signed and notarized by Apple, and the app refuses to start if its code has been modified.

The full security model is in the README, and all of the code is on GitHub.

Can I build it myself?

Sure. You need Node.js 20 or newer and Git. Build macOS packages on a Mac and Windows packages on Windows.

Terminal
git clone https://github.com/AvvaMobile/ChatGPT.Tabbed.git
cd ChatGPT.Tabbed
npm ci
npm run dev            # try it without packaging
npm run package        # macOS: .dmg files in release/
npm run package:win    # Windows: installer and .zip in release\

The README covers tests, signed macOS builds and how releases are published.

Is there anything it doesn't do?

  • It doesn't reopen your tabs after a restart. Each launch starts with one new chat, and older chats are in ChatGPT's sidebar.
  • It doesn't update itself. Download a new version from the releases page when one comes out.
  • It isn't an API client and doesn't use API keys. It uses your normal ChatGPT account and plan.
  • Each tab uses its own memory, like a browser tab. Dozens of open tabs will use more memory.
  • It's an independent project and isn't made or endorsed by OpenAI.
